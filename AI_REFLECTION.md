# AI Collaboration Reflection

**Project:** Football League Standings CLI — English First Division 1974/75  
**AI Coding Assistant:** OpenAI Codex CLI  
**Programming Language:** Python

## Reflection

Throughout this assessment, I used OpenAI Codex CLI as a coding assistant to review, improve, test, and validate my Python application. I approached the collaboration by asking Codex to first inspect the existing implementation and identify potential weaknesses rather than immediately modifying the code. This helped me understand which parts of the application were already functioning correctly and where improvements were necessary. One significant issue Codex identified was an `OverflowError` when processing unusually large football scores. After reviewing the cause, I chose to address the underlying floating-point conversion rather than introduce an arbitrary limit on valid scores. Codex implemented an integer-arithmetic solution while preserving the exact `Fraction` calculations used for league rankings. Additional regression tests confirmed the correction, and the existing historical standings remained unchanged.

A particularly valuable part of the collaboration was validating the historical football results. The initial testing approach compared the application's output against a CSV file generated by the same application. Although this was useful for detecting regressions, I recognised that it could not independently establish whether the historical data was correct. I therefore directed Codex to compare the match results against external historical records and verify the standings separately. During this process, we identified a discrepancy involving Arsenal and Tottenham Hotspur in a published league table. The source placed Tottenham above Arsenal, despite Arsenal having a higher goal average under the historical ranking rules. Rather than changing the application simply to match the published table, we retained the mathematically consistent ranking and documented the discrepancy. This reinforced the importance of evaluating external information critically instead of assuming that a published result is automatically correct.

This experience demonstrated the value of using AI as a collaborative development tool rather than treating its output as automatically correct. Codex was particularly useful for identifying edge cases, explaining potential failures, implementing focused improvements, and extending automated test coverage. The test suite increased from 35 to 42 passing tests, covering scenarios such as very large scores, exact goal-average comparisons, and independently verified historical results. I also used Git and project documentation checks to prepare the application for a reproducible submission. My main takeaway is that effective AI-assisted development requires clear instructions, an understanding of the underlying logic, independent verification, and deliberate technical decisions. The AI accelerated the development and review process, while responsibility for correctness and the final solution remained with me.
